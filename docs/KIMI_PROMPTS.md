# Промты реализации фирменных стилей

Очередь заданий, приводящая публичную страницу мастера к состоянию
**ONE PRODUCT · ONE BUSINESS LOGIC · SEVEN DISTINCT VISUAL WORLDS.**

Каждый промт скопирован в Kimi отдельным сообщением и рассчитан на чистый
контекст: факты, пути и критерии приёмки указаны внутри. Порядок обязателен —
обоснование в разделе «Зависимости».

Связанные документы: [BRAND_STYLE_ARCHITECTURE.md](../BRAND_STYLE_ARCHITECTURE.md) —
архитектура движка и композиций; [BRAND_STYLES.md](../BRAND_STYLES.md) — чем
миры являются; [DESIGN_STUDIO.md](../DESIGN_STUDIO.md) — как мастер до них
доходит; [DESIGN_AUDIT.md](../DESIGN_AUDIT.md) — аудит, подтвердивший проблему.

## Решения, которые пересматривать не нужно

1. **Композиций семь:** `soft`, `poster`, `editorial`, `minimal`, `luxury`, `organic`, `neo-glass`.
2. **`soft-studio` делит композицию с `soft`** — одна школа, различие в палитре и шрифтах.
3. **`soft` и `poster` не переделываются.** Их вид утверждён; они переносятся механически и обязаны совпасть со скриншотами M0 попиксельно на всём протяжении программы.
4. **С нуля строятся пять миров:** `minimal`, `luxury`, `editorial`, `organic`, `neo-glass`.
5. **Алиас — только временное состояние миграции**, не конечное.
6. **Общими навсегда остаются:** слой токенов, поведение шторки (фокус-ловушка, ESC, скролл-лок), закон `prefers-reduced-motion`, весь движок записи, сцена контактов со слотами, страница статуса `/booking/[token]`.
7. **Не предмет работы:** шрифтовые пары (закреплены `theme.test.ts`), иконки (`@phosphor-icons/react`, веса по мирам в BRAND_STYLES.md), палитры (измерены по WCAG).

## Зависимости и порядок

```
П0 ─ спека
П1 ─ референсы ──┐
П1-bis ─ тренды ─┤
                 ├─ П2 (тесты) ─ П3 (движок) ─ П4 (реестр) ─┬─ П5 Minimal ──┐
                 │                                          ├─ П6 Luxury    │
                 │                                          ├─ П7 Editorial ├─ П10
                 │                                          ├─ П8 Neo Glass │
                 └──────────────────────────────────────────┴─ П9 Organic ──┘
```

П3 обязан пройти до П5: если разрезать миры раньше слияния машины записи, она
размножится в семь копий вместо двух. П5–П9 независимы после П4 — единственное
место, где программа распараллеливается.

П2–П4 — примерно неделя, в которой не меняется ни один пиксель. Первый видимый
результат появляется на П5. Полная программа — **32–44 рабочих дня**.

## Блок: Правила ассетов

Действует в П5–П9. Kimi читает его из этого файла.

1. **Приоритет — сгенерировать, а не скачать.** Зерно, шум, льняная фактура,
   вуаль, виньетка, градиентные сетки, blur-подложки делаются CSS/SVG прямо в
   `compositions/<key>/`: это ноль килобайт, ноль лицензионных вопросов, работает
   в обеих темах. Скачанная растровая текстура рассматривается только если
   CSS/SVG объективно не даёт нужного результата — с объяснением почему.
2. **Внешний ассет — только с явной коммерческой лицензией** (SIL OFL, CC0, MIT,
   Unsplash/Pexels License). На каждый файл — строка в
   `docs/references/<key>/ASSETS.md`: файл, источник, URL, лицензия, дата.
   Ассеты без прослеживаемой лицензии не берём: это SaaS, не макет.
3. **Фотографии людей.** Для демо-контента и миниатюр Студии — только снимки, где
   лицо не является узнаваемым главным объектом, либо кадры рук, текстур,
   инструментов, интерьера. Коммерческое использование узнаваемого лица требует
   model release, которого стоковая лицензия может не давать.
4. **Всё раздаётся с нашего домена:** `apps/web/public/worlds/<key>/`. Никаких
   ссылок на внешние CDN в коде — отказоустойчивость, приватность, предсказуемый
   LCP. Внешние домены для фотографий мастеров (`images.remotePatterns` в
   `next.config.ts`, сейчас пустой) настраиваются отдельным решением.
5. **Бюджет:** суммарный вес ассетов мира — не больше 150 КБ после оптимизации.
   SVG для графики, WebP/AVIF для растра, `next/image` для всего растрового.
   Не укладывается — сообщить, а не превысить молча.
6. **Не меняется:** шрифтовые пары (`theme-brand.ts` + `theme.test.ts`), иконки
   (`@phosphor-icons/react`, веса по мирам в BRAND_STYLES.md), палитры
   (измерены по WCAG).

## Блок: Критерии приёмки мира

Действует в П5–П9.

1. `soft` и `poster` не меняют рендер ни на пиксель — сравнение со скриншотами M0
   обязательная часть шага.
2. Страница в grayscale без фотографий узнаётся как этот мир и не совпадает по
   композиции ни с одним из уже сделанных.
3. Сверка с `docs/references/<key>/REFERENCE.md` пройдена по каждому пункту;
   расхождения с BRAND_STYLES.md вынесены вопросом, а не решены молча.
4. Мир реализует все слоты контракта; частичных композиций не бывает.
5. Композиция не содержит хардкода цвета — только `var(--…)`, чтобы overrides
   мастера доезжали.
6. Композиция не импортирует `engine/api`, `engine/data` и другие композиции.
7. A11y: фокус-кольца, цели 44px, `aria-pressed`, `role="alert"` на ошибках,
   подписи через `engine/a11y.ts`.
8. `prefers-reduced-motion` гасит все анимации мира.
9. Алиас снят в реестре, строка вычеркнута из burn-down в TASKS.md.
10. `pnpm lint && pnpm typecheck && pnpm test && pnpm build` зелёные.
