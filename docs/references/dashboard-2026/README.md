# Прототип «Кабинет 2026» — исходники

Снимок опубликованного артефакта «AMOLIE Кабинет 2026» (версия `1789279412-e95d`), выложенный в репозиторий как эталон дизайна для переноса в сборку.

Это **не** часть приложения: файлы не собираются, не линтуются и не попадают в бандл. Они живут здесь как источник правды по композиции, отступам и поведению экранов кабинета.

## Что внутри

| Файл                         | Что содержит                                                             |
| ---------------------------- | ------------------------------------------------------------------------ |
| `amolie-dashboard-2026.html` | **Однофайловая сборка.** Всё вложено внутрь: открывается двойным кликом. |
| `index.html`                 | Разметка стенда: панель ролей, экранов, темы и устройства                |
| `styles.css`                 | Токены и вся вёрстка кабинета                                            |
| `data.js`                    | Примерные данные: люди, услуги, клиенты, записи, финансы                 |
| `ui.js`                      | Примитивы: кнопки, значки, статусы, портреты, форматирование             |
| `screens-cabinet.js`         | Экраны кабинета мастера и салона                                         |
| `screens-admin.js`           | Экраны администратора платформы                                          |
| `calendar.js`                | День, неделя, командный день, «Записи»                                   |
| `sheets.js`                  | Шторки и модальные окна                                                  |
| `app.js`                     | Оболочка: боковая панель, шапка, маршрутизация, ⌘K, тема, телефон        |

## Как смотреть

Однофайловая сборка открывается прямо из файловой системы:

```bash
open docs/references/dashboard-2026/amolie-dashboard-2026.html
```

Раздельные файлы требуют http (модули читаются относительными путями):

```bash
python3 -m http.server 8765 --directory docs/references/dashboard-2026
```

Дальше — `http://127.0.0.1:8765/`.

## Как устроено

- **Роли.** Пять: соло-мастер, владелица салона, администратор салона, наёмный мастер, администратор платформы. Список экранов в каждой роли свой.
- **Экраны.** 28 зарегистрированных в `window.P.SCREENS`; с учётом ролевых вариантов — 140 сочетаний «роль × экран».
- **Тема и устройство.** Переключаются в верхней панели стенда; телефон — рамка 390 px с настоящими мобильными раскладками, а не уменьшенный десктоп.
- **Шрифты.** Прототип набран Golos Text и Piazzolla с Google Fonts. **В сборке кабинета гарнитуры другие** — Onest и Playfair по Design System V2; переносить шрифты прототипа не следует, это отдельное решение владельца.

## Что учесть при переносе

- Данные в `data.js` — примерные, дат и сумм из них в код брать нельзя.
- Разметка прототипа писана строками (`innerHTML`), а не компонентами: в сборку переносится композиция и значения, а не сам код.
- Палитра прототипа уже перенесена в `tokens.css` (слой 1, 2026-09-13) с поправкой двух оттенков под AA. Структурные слои переносятся отдельно.
