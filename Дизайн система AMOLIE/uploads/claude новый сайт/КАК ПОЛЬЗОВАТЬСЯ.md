# Как пользоваться AI-RULES

Файл `AI-RULES.md` — свод правил, по которым нейронка собирает сайты, не похожие на нейронку.
Он **не заменяет** твои настройки. Он добавляется к ним слоем сверху.

---

## Вариант 1 / Claude Code, Cursor, Windsurf (проект в папке)

1. Положи `AI-RULES.md` в корень своего проекта, рядом с `index.html`.
2. Напиши агенту одно сообщение:

```
Прочитай AI-RULES.md в корне проекта и следуй ему.
Не переписывай CLAUDE.md — просто добавь эти правила к текущим.
Дальше работаем по нему: §0 перед стартом, §9 перед каждой выдачей.
```

**Если у тебя уже есть `CLAUDE.md`** и хочется, чтобы правила подхватывались автоматически в каждой сессии — добавь в него одну строку:

```
@AI-RULES.md
```

Свой `CLAUDE.md` при этом остаётся как был, ничего перезаписывать не нужно.

---

## Вариант 2 / чат без проекта (Claude, ChatGPT, Gemini)

Прикрепи `AI-RULES.md` первым сообщением и напиши:

```
Это мои правила по дизайну сайтов. Следуй им во всём, что собираешь.
Перед вёрсткой выполни §0, перед выдачей прогони §9.
Начни с §0: задай мне вопросы про референс и материалы.
```

---

## Чего ждать

Правильно подключённый файл меняет поведение сразу:

- нейронка **не бросится верстать с первого сообщения** — сначала спросит референс и фотографии;
- выдаст список токенов (шрифты, цвета, кривая) до кода;
- предложит одну из трёх схем композиции вместо заголовка по центру;
- сама попросит у тебя фото или даст конкретные запросы для Unsplash;
- в конце отчитается по чек-листу.

Если ничего этого не произошло — она файл не прочитала. Напиши прямо: «Ты прочитал AI-RULES.md? Подтверди строкой AI-RULES v3 active и выполни §0».

---

## Как проверить, что стало лучше

Собери один и тот же экран дважды: без файла и с ним. Смотри на три вещи.

1. **Первый экран.** Помещается ли всё в один экран и видна ли кнопка без скролла.
2. **Заголовок.** Плотная межстрочка, минусовой трекинг, строки одинаковой длины, ни одного одинокого слова.
3. **Фото.** Есть ли они вообще, идут ли во всю ширину, лежит ли текст в спокойной зоне кадра без чёрной подложки.

Разница видна именно здесь.
