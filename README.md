# AMOLIE

SaaS-платформа онлайн-записи для мастеров индустрии красоты в Латвии. Мастер
получает страницу `amolie.com/{slug}`, публикует свободные окна и принимает
записи; клиент записывается без регистрации.

**Статус:** Phase 1 пройдена, кроме уведомлений. В продакшене только лендинг —
бэкенд не развёрнут по решению владельца. Что сделано и что осталось —
[ROADMAP.md](ROADMAP.md), задачи — [TASKS.md](TASKS.md).

## Запуск

```bash
pnpm install
docker compose up -d          # PostgreSQL и Redis
cp apps/api/.env.example apps/api/.env   # заполнить DATABASE_URL, JWT_SECRET
pnpm --filter @amolie/api exec drizzle-kit migrate
pnpm dev                      # web :3000, api :3001
```

Если окружение поднималось до переименования в AMOLIE, база называлась `beauty_lv`, а
compose-проект — `beauty-lv`. Новый контейнер поднимется с пустой базой `amolie`; тома со
старыми именами остаются на диске и удалять их не обязательно:

```bash
docker compose up -d
pnpm --filter @amolie/api exec drizzle-kit migrate
pnpm --filter @amolie/api db:seed                         # демо-данные
```

Проверки перед коммитом — все четыре, они же в CI:

```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm build
```

## Устройство

Монорепозиторий на pnpm workspaces + Turborepo.

| Пакет                    | Что это                                                                        |
| ------------------------ | ------------------------------------------------------------------------------ |
| `apps/web`               | Next.js (App Router): лендинг, публичная страница, кабинет, админка            |
| `apps/api`               | NestJS + Drizzle + PostgreSQL                                                  |
| `packages/shared-kernel` | Доменные примитивы, общие для web и api: деньги, телефоны, слаги, темы, `.ics` |

Браузер никогда не обращается к API напрямую: клиентские компоненты ходят через
BFF-прокси `/api/proxy`, серверные — через `serverApiFetch`. Токен живёт в
httpOnly-cookie и в JavaScript не попадает.

## Два правила, которые легко нарушить не зная

**Флоу записи неприкосновенен.** Порядок «услуги → допы → время → контакты» и
подбор окон по суммарной длительности менять нельзя — переодевать визуально
можно. Услуги идут раньше времени не по вкусу: длительность визита решает, какие
окна вообще можно предложить.

**Две темы публичной страницы правятся раздельно.** Плакатная отвечает перед
скиллом `impeccable`, мягкая — перед `ui-ux-pro-max`; правка одной не переносится
на другую. Кабинет не принадлежит ни одной из них и судится по
[UI_GUIDELINES.md](UI_GUIDELINES.md). Подробности — [DESIGN.md](DESIGN.md).
