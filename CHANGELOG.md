### Added

### Changed

- `UI_GUIDELINES.md` (0.1 → 0.3): полноценная дизайн-система вместо ролей токенов. Разработана с применением anti-slop дисциплины `.agents/skills/design-taste-frontend/SKILL.md` (Design Read, дialы VARIANCE 6 / MOTION 5 / DENSITY 3, честная граница применения landing- vs product-правил). Зафиксированы: палитра (light/dark HEX), типографика (Onest + JetBrains Mono, отказ от Inter-дефолта), шкалы отступа/радиуса/тени/motion/z-index, полный инвентарь компонентов (навигация, кнопки, формы, карточки, calendar/time-slot picker, bottom sheet, toast/alert, empty/loading/error, PWA-состояния), запрет em-dash в интерфейсе.
- `UI_GUIDELINES.md` (0.3 → 0.4): палитра переведена с «Cold Petrol Luxury» на «Blush Rose» — нежные розовые тона под женскую аудиторию (явное указание пользователя, override premium-consumer запрета из SKILL.md, не отмена дисциплины: pastel-фон + более глубокий rose-акцент для прохождения WCAG AA на кнопках). Тёмная тема — тёплый приглушённый баклажан вместо холодного чёрного.
- Опубликован визуальный артефакт _Beauty.lv: UI Kit_ — живая витрина токенов и компонентов в палитре Blush Rose, с явным переключателем светлой/тёмной темы в шапке и двумя собранными экранами (кабинет мастера, публичная страница записи).
- `ARCHITECTURE.md` (0.1 → 0.3): добавлена мультитенантная модель поддоменов `{username}.beauty.lv` (карта доменов, резолюция тенанта, правила именования, изоляция данных, SEO), детализированы Storage/SMS/Email/Background Jobs/Queues/Caching/Security/Monitoring/Logging как отдельные разделы, добавлен раздел «Предлагаемые улучшения» (R2, Postgres RLS, Passkeys, react-email, собственные домены, edge-резолюция, единый клиентский аккаунт).
- `ARCHITECTURE.md` (0.2 → 0.3): корневой `beauty.lv` переопределён как сайт-визитка без каталога мастеров (публичный каталог убран из корневого домена, место — открытый вопрос); добавлены §3.6 «Вход и редирект на поддомен» и §10.1 «Регистрация мастеров по инвайт-коду (MVP)» — закрытая регистрация вместо открытой самостоятельной.
- `DATABASE.md` (0.1 → 0.2): уточнено назначение `organizations.slug` как username поддомена; добавлена таблица `invite_codes`.
- `API.md` (0.1 → 0.2): `POST /auth/register` теперь требует `inviteCode` для регистрации мастера; ответ `/auth/login` включает `redirectUrl`; добавлена группа admin-эндпоинтов управления инвайт-кодами.
- `PRD.md` (0.1 → 0.2): MVP-регистрация мастера — по инвайт-коду (закрытый запуск); маркетплейс/каталог явно не размещается на корневом `beauty.lv`.
- `ROADMAP.md`: Phase 1 — регистрация мастеров только по коду; Phase 4 — уточнено, что каталог не будет на корневом домене.
- `TASKS.md`: добавлены задачи A-11–A-14 (модель и админ-управление инвайт-кодами, валидация при регистрации, единый вход с редиректом на поддомен).
- Опубликован визуальный артефакт архитектуры (mermaid-схема системы, схема резолюции поддомена, карта доменов, сводка решений по слоям).
- `DATABASE.md`: отмечен статус реализации таблиц модуля 1 (`users`, `organizations`, `organization_members`, `invite_codes`), `organization_members.location_id` помечен как перенесённый в O-4.
- `DEPLOYMENT.md`: уточнён локальный запуск БД — `docker-compose.yml` или нативный Postgres, если Docker недоступен.

## [0.1.0] — 2026-07-30

### Added

- `CLAUDE.md` — постоянные правила разработки проекта (Production Ready, SOLID/DRY/KISS, Clean Architecture, Feature-Based Architecture, Mobile First, PWA, дизайн в духе Apple/Linear/Stripe/Notion).

- `UI_GUIDELINES.md` — дизайн-система: принципы, токены, брейкпоинты (Mobile First), гайдлайны компонентов, доступность, PWA-специфика.

- `ROADMAP.md` — фазы развития продукта от Discovery до AI & Automation.
