## Принцип ведения TASKS.md

- Задачи разбиваются на небольшие логические части в соответствии с [CLAUDE.md](CLAUDE.md) — крупная задача (`todo`) дробится на подзадачи перед началом реализации, а не выполняется одним большим изменением.
- Статус обновляется по мере выполнения; при появлении блокера — статус `blocked` с указанием причины (комментарием рядом со строкой).
- Задачи Phase 2+ добавляются в этот файл (новым разделом Epic) по мере приближения к соответствующей фазе roadmap, чтобы не перегружать документ задачами с низкой конкретикой на старте.
